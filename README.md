# VyralIQ

Premium AI-powered content creation platform for creators, entrepreneurs, and businesses.

## Tech Stack
- Flutter (Android, iOS, Web)
- Firebase (Auth, Firestore)
- OpenAI API

## Getting Started
```bash
flutter pub get
flutter create . --platforms android,ios,web
flutter run
```
